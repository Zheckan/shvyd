# Findings

This document records what agents and humans learn while working in this
repository: concise, verified, project-wide surprises, recurring sources of
confusion, and non-obvious constraints.

## How to record

- Verify before recording: run the command or read the file that proves it.
- Record outcomes and durable facts, not the steps taken to discover them.
  This document is not a work log.
- Never record secrets or credentials.
- Correct or remove a finding as soon as it stops being true. A stale finding
  is worse than a missing one.
- Keep each finding short enough that the next reader can act on it without
  asking how.

## FINDINGS

- `scripts/check-demo.py` and `scripts/check-extension.py` translate through
  the real providers. Without Azure or DeepL keys in `.env` they time out at
  `demo translation to uk`; that failure says nothing about the code.
- `src/domain/languages/language-data.json` is generated by
  `bun run languages:update`, which needs provider keys. Do not edit it by
  hand; Prettier ignores it.
- TypeScript 7 has no `baseUrl`. The `@/*` alias in `tsconfig.json` uses a
  `paths` entry relative to the config file, and Bun reads the same mapping
  for builds, tests, and scripts.
- `python3 scripts/check-extension.py --settings-only` checks the installed
  options page in a temporary Helium profile, including real Azure and DeepL
  connection tests. Each test translates `Hello`, using five source characters.
  Results go to `.preview/settings-extension-check/`; the full extension run
  keeps its separate `.preview/extension-check/` output.
